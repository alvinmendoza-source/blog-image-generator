Real infographic styles — icons, charts & flows (v2)

These carry meaning visually: process flows with icon nodes + arrows, donut/ring charts, pictographs, and a roadmap path — not text in boxes. Each still adapts to content (process → flow, numbers → chart/pictograph, comparison → bars) and stays on-brand.
